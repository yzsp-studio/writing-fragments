## 🇨🇳 中文

跑一场「拷问式」访谈，把用户脑子里跟某个写作话题相关的碎片挖出来——观点、场景、犀利句子、半成形的想法、引言，什么都收，追加到同一个 Markdown 文件里作为未来成文的原料。输入只有写作主题和保存路径，输出是一份不断增长的 fragments 文档，每条碎片用 `---` 分隔，不强加阶段、目录、日期、tag 或大纲。它从初始 prompt 就抓第一条碎片、不等第二轮，首次写入创建 H1 工作标题加正文，随后立刻把文件注册到 session，让它出现在工作区文件面板里可直接编辑。适合在给结构之前先把想法铺开、就一个写作话题给自己做口述访谈、或者纯攒原始素材的阶段。

### ✨ 能做什么

- 一问一答的拷问式访谈，围着同一个写作话题持续追问
- 抓异质素材：观点、场景、金句、半成形想法、引言
- 每条碎片用 `---` 分隔，全部追加进同一个 Markdown 文件
- 不写 metadata、目录、日期、tag，也不强加大纲和阶段
- 初始 prompt 即产出第一条碎片，不等第二轮
- 首次写入后注册到 session，文件面板里可直接编辑

## 🇬🇧 English

Runs a grilling self-interview that digs out every fragment in your head around a writing topic — opinions, scenes, sharp sentences, half-formed ideas, quotes — and appends them to a single Markdown file as raw material for later writing. Input is just a writing topic and a save path; output is one growing fragments document with entries separated by `---`, with no imposed stages, outline, table of contents, dates or tags. It captures the first fragment from the initial prompt rather than waiting for a second turn, and on first write creates an H1 working title plus the body, then immediately registers the file to the session so it appears in the workspace file panel for direct editing. Best for spreading ideas out before committing to structure, dictating a topic to yourself, or simply stockpiling raw material.

### ✨ What it does

- A grilling one-question-at-a-time interview that keeps pressing on one writing topic
- Harvests heterogeneous material: opinions, scenes, sharp lines, half-formed ideas, quotes
- Every fragment separated by `---` and appended to one Markdown file
- No metadata, table of contents, dates or tags, and no imposed outline or stages
- Produces the first fragment from the initial prompt instead of waiting a turn
- Registers the file to the session after the first write so it is directly editable in the file panel
